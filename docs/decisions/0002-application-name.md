# ADR 0002 · WaveTandem name

Accepted.

SyncEar was the original working name. A separate [SyncEar audio sharing project](https://github.com/wa4lo7k/SyncEar) already uses it. WaveTandem is the application, source, binary and archive name. The original repository URL identifies the existing workspace on GitHub.

At selection time, exact-name searches found no WaveTandem result on GitHub, and the NuGet and npm package endpoints returned no matching package. Formal trademark clearance remains open.
