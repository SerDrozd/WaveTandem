# Security policy

Report suspected vulnerabilities using the repository's private vulnerability reporting form if enabled. Include an affected version, a minimal reproduction and the expected impact. Keep sensitive device names, logs and audio recordings out of public issues. If private reporting is unavailable, open a public issue asking the maintainer for a private contact channel without including vulnerability details.

WaveTandem handles audio locally and stores preferences in the user's Windows profile. Use the latest published version when testing a report. Release archives can be checked against their SHA-256 sidecars. Release binaries are unsigned unless a particular release explicitly says otherwise.
